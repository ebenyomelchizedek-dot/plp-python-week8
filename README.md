# Python Week 8 Final Project – My Python Toolkit

## Project Description

My Python Toolkit is a menu-driven program that provides three useful tools.

1. **Simple Calculator:** Performs addition, subtraction, multiplication and division.
2. **To-Do List:** Allows users to add and view tasks using a Python list.
3. **Even or Odd Checker:** Checks whether a whole number is even or odd.

## Files Included

- `toolkit.py` – Contains the complete Python toolkit program.
- `toolkit_plan.txt` – Contains the project plan and menu design.
- `README.md` – Provides project information and instructions.
- `screenshots/` – Contains screenshots showing the menu and each tool in action.

## How to Run the Program

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python toolkit.py
```

4. Select a tool from the menu and follow the instructions.
